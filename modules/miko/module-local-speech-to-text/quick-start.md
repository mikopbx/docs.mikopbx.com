# Быстрый старт

Для текущей связки используйте ModuleLocalSpeechToText **1.45** и Local STT Worker **1.7 build 34**. Worker работает на macOS 14.0 или новее на Mac с Apple Silicon.

{% hint style="warning" %}
Если вы обновляете существующую установку, сначала обновите модуль до 1.45, а затем Local STT Worker до 1.7. Старый Worker после обновления модуля будет отображаться как несовместимый и офлайн. Существующий ключ доступа сохраняется.
{% endhint %}

### Установка модуля

1. Откройте веб-интерфейс MikoPBX.
2. Перейдите в раздел **Модули** → **Маркетплейс модулей**.

<figure><img src="../../../.gitbook/assets/MikoPBXModuleMarketplace.png" alt=""><figcaption><p>Маркетплейс модулей</p></figcaption></figure>

3. Найдите **Модуль локальной транскрибации** и установите его.
4. Откройте список установленных модулей и включите модуль.

<figure><img src="../../../.gitbook/assets/STTModuleInstalledModulesSection.png" alt=""><figcaption><p>Включение модуля локальной транскрибации</p></figcaption></figure>

5. Нажмите кнопку настроек справа от версии модуля.

<figure><img src="../../../.gitbook/assets/STTModuleOpen.png" alt=""><figcaption><p>Переход на страницу модуля</p></figcaption></figure>

### Первичная настройка модуля

1. На вкладке **Настройки** оставьте язык **Определять автоматически** или выберите основной язык звонков.
2. Проверьте **Максимальную длительность распознаваемой записи**. Значение по умолчанию — 60 минут.
3. Выберите **Период обработки записей** и **Срок хранения расшифровок**. Период обработки не должен превышать срок хранения.
4. При необходимости добавьте внутренние названия и сокращения в список терминов.
5. Сохраните настройки.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/STTModuleSettingsPageFastStart.png" alt=""><figcaption><p>Прежний вид страницы настроек</p></figcaption></figure>

{% hint style="info" %}
Размер файла больше не настраивается. Модуль всегда применяет фиксированный защитный предел 500 MiB.
{% endhint %}

### Выбор модели

1. Откройте вкладку **Каталог моделей**.
2. Для большинства звонков выберите **Large V3 Turbo**. Для русской разговорной речи можно использовать **Podlodka Turbo**.
3. Нажмите **Сохранить модель**.

<figure><img src="../../../.gitbook/assets/STTModuleChoosingModel.png" alt=""><figcaption><p>Выбор модели распознавания</p></figcaption></figure>

Модель будет загружена на Mac при первом задании. Для первой загрузки необходим доступ к Hugging Face.

### Создание ключа Worker

1. Откройте вкладку **Обработчики**.
2. Нажмите **Создать ключ доступа**.
3. Сразу скопируйте показанный токен: после обновления страницы его нельзя будет посмотреть повторно.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/STTModuleCreatingANewWorkerKey.png" alt=""><figcaption><p>Прежний вид вкладки обработчиков</p></figcaption></figure>

Для каждого Mac рекомендуется создавать отдельный ключ. Один ключ нельзя привязать к нескольким UID обработчиков.

### Подключение Local STT Worker

Установите и откройте приложение **Local STT Worker**. При первом запуске появится онбоардинг из трех шагов.

#### Шаг 1. Язык

Выберите русский или английский язык интерфейса и нажмите **Далее**. При смене языка уже запущенного приложения может потребоваться перезапуск; после него онбоардинг откроется снова.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAIWorkerChooseLang.png" alt=""><figcaption><p>Прежний экран выбора языка MIKO AI Worker</p></figcaption></figure>

#### Шаг 2. Подключение к MikoPBX

Заполните поля:

| Поле | Что указать |
| --- | --- |
| **Адрес MikoPBX** | Адрес вида `https://pbx.example.com` без логина и пароля в URL. |
| **Имя обработчика** | Понятное имя Mac, которое будет видно в MikoPBX. |
| **Токен STT Worker** | Ключ, созданный на вкладке **Обработчики**. |

Токен сохраняется в macOS Keychain и не записывается в журналы.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAIWorkerPBXAddress.png" alt=""><figcaption><p>Прежний отдельный экран адреса PBX</p></figcaption></figure>

В раскрывающемся блоке **Дополнительные настройки** доступны:

* проверка TLS-сертификата;
* необязательный PEM-файл собственного CA;
* стабильный UID обработчика.

Без необходимости не меняйте UID: MikoPBX использует его как постоянный идентификатор этого Mac.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAIWorkerTLSCert.png" alt=""><figcaption><p>Прежний отдельный шаг настройки TLS</p></figcaption></figure>

Нажмите **Подключить и продолжить**. Приложение выполнит `GET /worker-api-contract`, проверит Worker API v2 и зарегистрирует Mac через `POST /workers`.

Если модуль или Worker несовместимы, приложение остановит подключение и покажет требование обновления. Оно не переключается на старый Worker API v1.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAISttRegister.png" alt=""><figcaption><p>Прежний отдельный экран регистрации STT</p></figcaption></figure>

#### Шаг 3. Завершение

Проверьте состояние MikoPBX и Speech to Text. При необходимости включите **Запускать при входе**, затем нажмите **Открыть Local STT Worker**.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAIWorkerOnboardSummary.png" alt=""><figcaption><p>Прежний итоговый экран MIKO AI Worker</p></figcaption></figure>

В приложении откройте **Обзор**. Если обработчик остановлен, нажмите **Запустить обработчик** или включите в настройках **Поддерживать работу обработчика**. При этой настройке Worker автоматически возобновляет работу после восстановления сети или пробуждения Mac.

### Проверка работы

1. Совершите звонок, для которого включена запись разговора.
2. Дождитесь появления задания на вкладке **Очередь** модуля.
3. При первом запуске дождитесь загрузки модели на Mac.
4. Проверьте локальные этапы в разделе **Обзор** или события в разделе **Диагностика**.
5. Откройте готовый результат на вкладке **Расшифровки** в MikoPBX.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/STTWorkerProcess.png" alt=""><figcaption><p>Прежний главный экран обработчика</p></figcaption></figure>

Если результат не появляется, проверьте на вкладке **Обработчики** версию приложения, версию API и состояние **Совместим**, затем откройте **Диагностика** в Local STT Worker.

Подробное описание экранов и диагностики приведено в статье [Local STT Worker](miko-ai-worker.md).
