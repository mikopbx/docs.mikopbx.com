# Быстрый старт

### Перед началом

Для работы понадобятся:

* MikoPBX 2025.1.1 или новее;
* ModuleAISupervisor 1.73;
* установленный и настроенный модуль локального распознавания речи;
* AI Supervisor Worker 1.7 build 34;
* Mac с Apple Silicon и macOS 14 или новее;
* доступ Mac к веб-интерфейсу MikoPBX.

{% hint style="info" %}
ИИ Супервайзер анализирует готовые расшифровки. Если распознавание речи ещё не настроено, сначала выполните [быстрый старт модуля локального распознавания речи](../module-local-speech-to-text/quick-start.md).
{% endhint %}

{% hint style="warning" %}
При обновлении сначала установите ModuleAISupervisor 1.73, затем AI Supervisor Worker 1.7 build 34. Эти версии используют worker API v2 и не имеют fallback на API v1.
{% endhint %}

### Настройка модуля

#### 1. Создайте ключ обработчика

1. Откройте **Настройки** → **Обработчики**.
2. Нажмите кнопку создания ключа доступа.
3. Сразу скопируйте показанное значение.

Полный ключ отображается только один раз. После закрытия окна в списке останутся только безопасные сведения о ключе.

{% hint style="warning" %}
Для AI Supervisor Worker нужен отдельный ключ ИИ Супервайзера. Токен Local STT Worker здесь не подходит.
{% endhint %}

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/AIModulesSettingsConnection.png" alt=""><figcaption><p>Прежний экран создания ключа доступа</p></figcaption></figure>

#### 2. Выберите состав анализа и модель

Откройте **Настройки** → **ИИ-анализ**.

Для первого запуска рекомендуется:

* **Сводка** — включена вместе с автоматическим ИИ-анализом;
* **Голосовые метрики** — включены;
* **Анализ эмоций** — включите при необходимости;
* **Акустический анализ** — включите при необходимости;
* профиль **Qwen3 8B Instruct Q4** — сбалансированный вариант;
* профиль **Qwen3.5 4B Q4** — для Mac с меньшим объёмом памяти;
* профиль **Qwen3.5 9B Q4** — для более подробного анализа длинных звонков.

Настройки сохраняются автоматически. Кнопки **Сохранить настройки** в текущем интерфейсе нет.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/AIModuleAIAnalysisQuickStart.png" alt=""><figcaption><p>Прежний вид параметров анализа</p></figcaption></figure>

#### 3. Включите поток звонков

Откройте **Настройки** → **Поток звонков** и проверьте:

* **Автоматический ИИ-анализ** включён;
* **Автоматический импорт** включён;
* выбран нужный язык результата;
* обработка внутренних звонков включена, если она требуется;
* установлен подходящий срок хранения данных.

Если готовые расшифровки уже накопились, нажмите кнопку ручного запуска импорта.

### Настройка AI Supervisor Worker

AI Supervisor Worker — отдельное приложение только для ИИ-анализа. В нём нет режима распознавания речи и настроек Local STT Worker.

#### 1. Выберите язык

Откройте приложение **AI Supervisor Worker**. На первом этапе выберите язык интерфейса и нажмите **Продолжить**. Если приложение предложит перезапуск после смены языка, выполните его.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAIWorkerChooseLang.png" alt=""><figcaption><p>Прежний экран выбора языка</p></figcaption></figure>

#### 2. Подключитесь к MikoPBX

На этапе подключения укажите:

* адрес MikoPBX в формате `https://...` или `http://...`;
* понятное имя этого Mac;
* ключ AI Supervisor Worker, созданный в модуле.

Ключ сохраняется в macOS Keychain.

Откройте **Расширенные настройки**, только если нужно изменить стабильный UID обработчика, проверку TLS или выбрать собственный PEM-файл CA. Нажмите **Подключить и продолжить** — приложение проверит адрес, ключ и контракт worker API v2.

#### 3. Подготовьте локальный ИИ

На этапе **Подготовка локального ИИ** приложение последовательно проверяет:

1. локальную среду Ollama;
2. модель, выбранную в MikoPBX;
3. готовность обработчика.

Если Ollama не установлена, нажмите **Установить Ollama**. После установки нажмите **Подготовить и запустить**. Приложение загрузит выбранную модель, зарегистрирует этот Mac и запустит обработчик.

Первая загрузка модели может занять продолжительное время. Не закрывайте приложение и убедитесь, что на Mac достаточно свободного места.

#### 4. Завершите настройку

На последнем этапе проверьте состояния **MikoPBX**, **Локальная модель** и **AI Worker**.

При необходимости включите:

* **Запускать при входе** — открывать приложение после входа в macOS;
* **Поддерживать работу обработчика** — автоматически возобновлять работу после восстановления сети или PBX.

Нажмите **Открыть AI Supervisor Worker**.

### Проверка результата

1. В AI Supervisor Worker откройте **Обзор**. Состояние должно показывать готовность к новым заданиям.
2. В разделе **Модели** проверьте Ollama и модель, выбранную MikoPBX.
3. В MikoPBX откройте **Настройки** → **Система** → **Обработка** и убедитесь, что задания переходят из ожидания в работу.
4. После завершения откройте вкладку **Звонки** и выберите обработанный звонок.

В AI Supervisor Worker история локальной обработки находится в разделе **Активность**, а подключение, готовность модели и журнал — в разделе **Диагностика**.

<p><mark style="color:red;">Устарело</mark></p>

<figure><img src="../../../.gitbook/assets/MIKOAiWorkerAnalysisProcess.png" alt=""><figcaption><p>Прежний экран процесса анализа</p></figcaption></figure>

{% hint style="info" %}
Если задание находится в состоянии `waiting_for_stt`, оно ожидает доступную расшифровку или её снимок. Такое ожидание не расходует попытки ИИ-анализа. Проверьте модуль Local Speech To Text и состояние снимков в **Настройки** → **Система** → **Диагностика**.
{% endhint %}
