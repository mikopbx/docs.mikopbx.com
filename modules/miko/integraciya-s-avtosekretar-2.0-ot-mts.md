# Интеграция с Автосекретарь 2.0 от МТС

### Кому будет полезно? <a href="#komu-budet-polezno" id="komu-budet-polezno"></a>

Если есть разъездные сотрудники, кому удобнее использовать мобильные телефоны и не требуется интеграция с 1С - в этом случае руководитель получит доступ к истории звонков и записям разговоров сотрудника в АТС и в 1С.

В частном случае, может быть полезно, если уже есть множество FMC SIM карт, от которых нет возможности отказаться.&#x20;

### Настройка Автосекретарь 2.0

Необходимо создать API ключ:

<figure><img src="../../.gitbook/assets/Снимок экрана 2025-12-24 в 14.55.45.png" alt=""><figcaption></figcaption></figure>

Далее прописать параметры подключения к MikoPBX для возможности отправки информации о  звонках:

1. Перейдите во вкладку «Предприятие», выберите номер предприятия
2. Перейдите во вкладку Тариф и услуги;
3. Подключите услугу Интеграция с CRM, активировав слайдер
4. Выберите CRM из списка
5. Нажмите «Применить изменения»
6. Перейдите в раздел «CRM» для настройки интеграции
7. Затем из выпадающего списка выберите «Универсальный модуль CRM»

Перейдите в раздел "CRM":

<figure><img src="../../.gitbook/assets/Снимок экрана 2025-12-24 в 15.02.16.png" alt=""><figcaption></figcaption></figure>

* **CRM URL** - укажите публичный адрес web интерфейса MikoPBX, пример `https:/YOUR_PBX_HOST/pbxcore/api/mts-pbx/v1/event` в адресе замените "`YOUR_PBX_HOST`" на адрес вашего сервера
* **CRM логин** - укажите логин из настроек MikoPBX
* **CRM пароль** - укажите пароль из настроек MikoPBX&#x20;

{% hint style="info" %}
Обычно запросы на АТС поступают с адреса `213.87.44.111`, его следует добавить в белый список в сетевом экране. Доступ к интерфейсу следует разрешить только для этого адреса.&#x20;
{% endhint %}

### Настройки модуля

<figure><img src="../../.gitbook/assets/Снимок экрана 2025-12-24 в 14.53.29.png" alt=""><figcaption></figcaption></figure>

* **API Ключ** - укажите ранее полученный токен.
* **Логин REST** - должен совпадать с **CRM логин**
* **Пароль REST** - должен совпадать с **CRM пароль**

После заполнения настроек выполните действие "**Сохранить**".&#x20;

### История звонков в 1С

Актуально для модуля "Панель телефонии 4.0"

В архиве модуля есть файл ЗагрузкаИсторииЗвонковMtsPBX\_v1.epf - подключите его в 1С как внешнюю обработку. В настройках обработки заполните адрес сервера и offset укажите равным нулю.&#x20;

Настройте расписание загрузки истории звонков.&#x20;

{% hint style="info" %}
Предполагается, что модуль "Панель телефонии 4.0" уже настроен и работает через публикацию web сервисов на http сервере.&#x20;
{% endhint %}
