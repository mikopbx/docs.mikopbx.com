# Актуализация документации Local STT

## Цель

Привести русский блок `modules/miko/module-local-speech-to-text` в соответствие с `ModuleLocalSpeechToText` 1.45 и самостоятельным приложением Local STT Worker 1.7 build 34, сохранив существующие URL страниц.

## Объем

Обновляются три страницы:

- `README.md` — устройство модуля, настройки, очередь, обработчики, расшифровки, журнал, API и диагностика;
- `quick-start.md` — установка модуля и трехшаговое подключение Local STT Worker;
- `miko-ai-worker.md` — актуальное руководство по отдельному приложению Local STT Worker.

Имя файла `miko-ai-worker.md` сохраняется для совместимости с существующими ссылками. Заголовок, описание и текст страницы переводятся на актуальное название Local STT Worker.

## Источники истины

При расхождении источников приоритет имеют:

1. `module.json`, REST-контроллеры, модели настроек и текущие Volt-шаблоны модуля;
2. SwiftUI-экраны, настройки, API-клиент, `CHANGELOG.md` и метаданные Xcode Worker;
3. руководство `docs/worker-api-v2-migration.md`;
4. README репозиториев только в тех частях, которые подтверждаются кодом.

Устаревший `readme.ru.md` модуля не используется как источник версий и Worker API.

## Содержательные изменения

Документация должна отражать:

- отдельное приложение Local STT Worker без режимов AI Analysis;
- требования MikoPBX 2025.1.1+, модуль 1.45, Worker 1.7 build 34, macOS 14+ и Apple Silicon;
- обязательный порядок обновления: сначала модуль, затем Worker;
- Worker API v2, проверку контракта и новые resource-oriented маршруты;
- трехшаговый онбоардинг: язык, подключение, завершение;
- текущие разделы Worker: Обзор, История, Модели, Диагностика, Настройки;
- максимальную длительность записи вместо настраиваемого размера файла;
- фиксированный защитный предел файла 500 MiB;
- срок хранения расшифровок и его связь с периодом обработки;
- централизованный профиль обработки, который Worker получает от PBX;
- отсутствие пользовательского интерфейса расширенных параметров декодирования, VAD, сегментации и сетевых интервалов;
- совместимость Worker, версии приложения/API, структурированные журналы и актуальные сценарии диагностики.

Сохраняются актуальные сведения об архитектуре, локальном WhisperKit/Core ML, моделях, словаре терминов, очереди, lease, диалоговом представлении и read-only API расшифровок.

## Изображения

Существующие изображения не удаляются. Перед каждым заведомо устаревшим изображением добавляется отдельная строка:

```html
<p><mark style="color:red;">Устарело</mark></p>
```

Помечаются изображения старого MIKO AI Worker, прежнего онбоардинга и изменившихся экранов модуля. Общие изображения маркетплейса и установки модуля остаются без отметки, если описываемое действие не изменилось.

## Проверка результата

После редактирования необходимо проверить:

- отсутствие пользовательских инструкций про AI Analysis и MIKO AI Worker;
- отсутствие рабочих ссылок на Worker API v1;
- единообразие названий вкладок и кнопок с русскими локализациями кода;
- наличие красной отметки перед каждым устаревшим изображением;
- сохранность всех существующих путей изображений и внутренних ссылок;
- наличие страниц в `SUMMARY.md` без изменения их URL;
- отсутствие противоречий между тремя статьями.
