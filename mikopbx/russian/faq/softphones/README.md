# Настройка софтфонов

Помимо сторонних приложений из списка ниже, у MikoPBX есть фирменный софтфон [MikoTalk для iPhone и Android](mikotalk-mobile.md): push-звонки, история, контакты и подключение по QR-коду без ручной настройки SIP. Для работы с компьютера есть расширение [Softphone MikoPBX для Google Chrome](softphone-mikopbx-chrome.md).
