# MikoPBX 2026.8.2

Главное в выпуске MikoPBX 2026.8.2 - безопасность и исправления после 2026.6.99. Закрыты уязвимости в правах доступа к модулям, настройках провайдеров и обработке ответов DHCP-сервера. Вернулась переадресация на голосовую почту, «Занято» и «Отбой», снова работает установка модулей из маркетплейса, а из приветствий и музыки на удержании пропал щелчок.

{% hint style="warning" %}
Перед обновлением сделайте резервную копию. После обновления пользователям веб-интерфейса нужно один раз войти заново. Если станция работает на версии 2026.5.6, обновляйтесь ручной загрузкой образа IMG. Для станций, установленных до версии 2026.1.1, используйте образ IMG-legacy.
{% endhint %}

### Безопасность

Пользователь с ограниченной ролью больше не может вызывать действия модулей в обход прав доступа. Форма настройки пункта меню модуля больше не позволяет менять системные настройки и внедрять разметку в меню.

Значения в настройках провайдеров и календарей нерабочего времени больше не могут менять конфигурацию телефонии в обход интерфейса. Маршруты от DHCP-сервера проверяются: поддельный ответ в локальной сети больше не позволяет выполнять команды на станции.

Каждая станция получает собственный ключ шифрования сеанса входа. Данные импорта сотрудников из CSV, включая пароли телефонов, хранятся в защищённом месте и удаляются через час. При внутренних ошибках интерфейс показывает общее сообщение без служебных подробностей.

### Звонки и звук

Переадресация на голосовую почту, «Занято», «Отбой» и «DID на сотрудника» снова работает. Ранее вместо переадресации звонок долго поступал сотруднику. Эти варианты снова доступны в списках выбора входящих маршрутов, голосовых меню, очередей и переадресации.

Убран щелчок в начале голосовых меню, системных подсказок и музыки на удержании. Уже записанные файлы исправляются автоматически при запуске станции.

Музыка на удержании снова играет на новых установках. Если удалить все свои треки, станция использует встроенный набор.

### Модули

Снова работает установка модулей из маркетплейса.

### Сетевые фильтры и доступ

Сетевой фильтр, который используется сотрудником, провайдером, пользователем AMI или ключом API, нельзя удалить. Ранее после удаления фильтра такие записи теряли ограничение по адресам.

Ключи API с сетевым фильтром снова работают из разрешённых сетей. Ранее они отклонялись с любого адреса.

В LXC-контейнерах заблокированные адреса действительно теряют доступ к веб-интерфейсу, а белый список применяется сразу после перезагрузки.

### Прочие исправления

Новые установки больше не пытаются отправлять уведомления через ненастроенный почтовый сервер. Диски и разделы определяются правильно, даже если их больше девяти или у них похожие имена.

### Важно при обновлении

Если сотрудник, провайдер, пользователь AMI или ключ API был привязан к уже удалённому сетевому фильтру, после обновления доступ для него разрешён только с локальных адресов. Каждая такая запись указывается в системном журнале - назначьте ей нужный фильтр.
