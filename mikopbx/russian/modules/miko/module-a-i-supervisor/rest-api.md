# REST API

Модуль «Облачный ИИ Супервизор» анализирует звонки и показывает результаты в своем интерфейсе. Через REST API те же данные можно забрать в стороннюю систему — например, показать сводку и оценку разговора в CRM рядом с карточкой клиента и там же вести работу по звонку.

Базовый путь:

```
/pbxcore/api/v3/module-cloud-ai-supervisor
```

## Ключ доступа

1. Откройте **Система → API-ключи** и создайте новый ключ.
2. Выдайте ему права на строки этого модуля: чтение — для получения данных, запись в строку звонков — если планируете менять статусы и добавлять заметки.
3. Передавайте ключ в заголовке каждого запроса:

```bash
Authorization: Bearer ВАШ_КЛЮЧ
```

{% hint style="info" %}
Каждый ответ обернут в стандартный конверт: `result` (успех или нет), `data` (сами данные) и `messages` (текст ошибки). Ниже описано содержимое `data`.
{% endhint %}

## Список звонков с анализом

```bash
curl -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  "https://адрес-атс/pbxcore/api/v3/module-cloud-ai-supervisor/calls?period=7d&limit=50&offset=0"
```

Основные параметры:

* `period` — готовый период: `1d`, `7d` или `30d`; его можно сузить датами `date_from` и `date_to`;
* `search` — поиск по номеру, сотруднику, теме и статусу; точный звонок можно найти параметром `call_id`;
* `employee_numbers` — внутренние номера сотрудников через запятую;
* `direction` — `incoming`, `outgoing` или `internal`;
* `sentiment`, `quality`, `risk` — фильтры по тональности и уровням оценки и риска (`high`, `medium`, `low`);
* `review_status` — `reviewed` или `unreviewed`; `workflow_status` — `open`, `in_progress` или `closed`;
* `limit` и `offset` — постраничная выдача (по умолчанию 50 записей).

В каждом элементе списка: номер `id`, идентификатор звонка `call_id`, дата, длительность, номера и имена обеих сторон, а главное — блок `ai_result` с краткой сводкой `summary`, тональностью `sentiment`, оценкой риска `risk_score` (0–100) и оценкой качества `quality_score`.

## Карточка звонка

```bash
curl -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  "https://адрес-атс/pbxcore/api/v3/module-cloud-ai-supervisor/calls/12"
```

`id` берется из списка (или из точного поиска по `call_id`). В карточке помимо полей списка есть полная расшифровка `stt_detail.transcript` — реплики с ролями участников («клиент»/«сотрудник») и таймкодами, история работы по звонку `workflow_history` и детали оценки качества.

## Работа по звонку: статусы и заметки

```bash
curl -X PATCH -H "Authorization: Bearer ВАШ_КЛЮЧ" -H "Content-Type: application/json" \
  -d '{"workflow_status":"closed","close_reason":"Решено","note":"Клиент подтвердил исправление"}' \
  "https://адрес-атс/pbxcore/api/v3/module-cloud-ai-supervisor/calls/12"
```

Доступные поля:

* `reviewed` — отметить звонок просмотренным (`true`/`false`);
* `workflow_status` — статус работы: `open`, `in_progress`, `closed`;
* `assignee_id`, `assignee_label` — ответственный;
* `due_at` — срок (время Unix; `0` — убрать срок);
* `is_escalated` — эскалация;
* `close_reason` — причина закрытия, `note` — заметка (добавляется в историю).

Те же поля можно применить сразу к нескольким звонкам: запрос `PATCH /calls` с массивом `ids`.

## Сводка по команде

```bash
curl -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  "https://адрес-атс/pbxcore/api/v3/module-cloud-ai-supervisor/dashboard?period=30d"
```

Те же периоды, что и у списка. В ответе — количество звонков и разобранных разговоров, распределение по дням, часам и сотрудникам, средний риск, разбивка тональности, темы обращений и звонки, требующие внимания. Раздел удобно использовать для собственного дашборда.

## Расходы и состояние

* `GET /usage` — сколько звонков проанализировано, расход токенов и денег за период (`today`, `7d`, …), остаток баланса.
* `GET /health` — работает ли модуль и доступен ли источник расшифровок; пригодится для мониторинга.

{% hint style="info" %}
Остальные запросы модуля (настройки, очередь заданий, импорт расшифровок, скрипты качества, диагностика) обслуживают его веб-интерфейс. Своего протокола для приложений-обработчиков у модуля нет — анализ выполняется в облаке.
{% endhint %}
