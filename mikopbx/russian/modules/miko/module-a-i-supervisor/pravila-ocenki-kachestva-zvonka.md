# Правила оценки качества звонка

Модуль оценивает работу сотрудника по шкале от 0 до 100. ИИ находит в разговоре факты по каждому критерию и подкрепляет их цитатами, а модуль проверяет цитаты и рассчитывает итоговую оценку по единой методике.

Критерии объединены в шесть групп:

| Группа                         | Что проверяется                                                                                          |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| **Понимание запроса**          | Запрос понят, недостающие детали уточнены, важные детали подтверждены.                                   |
| **Правильность действий**      | Действия соответствуют запросу, информация обоснована, сотрудник взял ответственность за обращение.      |
| **Соблюдение скрипта**         | Требования [скрипта](pravila-ocenki-kachestva-zvonka.md#skripty), назначенного сотруднику, если он есть. |
| **Качество общения**           | Уважительное общение, понятное объяснение, внимание к клиенту и проверка понимания.                      |
| **Организация диалога**        | Разговор по делу, ожидание и перевод объяснены.                                                          |
| **Завершение и следующий шаг** | Следующий шаг согласован, срок согласован, результат проверен.                                           |

Оценка относится к одной из зон:

| Зона        | Оценка    |
| ----------- | --------- |
| **Низкое**  | до 50     |
| **Среднее** | 50–79     |
| **Высокое** | 80 и выше |

При наведении на оценку видно, сколько критериев удалось проверить, и результат по каждой группе. В карточке звонка также показываются блоки **Что получилось хорошо** и **Что улучшить** с рекомендациями сотруднику.

Несколько правил, о которых полезно знать:

* Если по звонку недостаточно подтвержденных данных, оценка не выставляется - звонок отмечается как **Не оценено**.
* Если подтверждена только часть критериев, оценка отмечается как **Неполная оценка** и учитывается в средних показателях с меньшим весом.
* Если клиент остался с нерешенной проблемой и следующий шаг не согласован, оценка не превышает 79.
* Подтвержденное нарушение критического требования скрипта ограничивает оценку значением 49.
* Если звонок переводили, каждый сотрудник оценивается отдельно за свою часть разговора и по своему скрипту. Оценка звонка - среднее по оцененным сотрудникам. В карточке появляются вкладки **Средний** и вкладки с именами сотрудников: в каждой - оценка сотрудника, его часть разговора, причина передачи, итог и ключевые цитаты.

{% hint style="info" %}
Звонки, проанализированные до перехода на текущую методику, показываются как **Не оценено**, пока не будут проанализированы заново. Их прежняя оценка доступна в свернутом блоке **Предыдущая оценка**.
{% endhint %}
