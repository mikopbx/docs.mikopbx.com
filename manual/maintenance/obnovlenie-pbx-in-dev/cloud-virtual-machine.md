# Обновление MikoPBX в облаке

Эта инструкция предназначена для MikoPBX, работающей как полноценная облачная виртуальная машина: из Marketplace либо из импортированного RAW, VHD или другого дискового образа.

Основной способ обновления облачной станции — через web-интерфейс с использованием `.img`-образа. Возможность загрузки с ISO зависит от конкретного облачного провайдера и не является универсальной.

{% hint style="danger" %}
Перед обновлением создайте две независимые точки восстановления: резервную копию настроек MikoPBX и snapshot системного диска или всей виртуальной машины в панели облачного провайдера.
{% endhint %}

## Перед началом

1. Проверьте, что у вас есть доступ к панели управления облаком и web-интерфейсу MikoPBX.
2. Сохраните резервную копию настроек MikoPBX вне обновляемой виртуальной машины.
3. Создайте snapshot системного диска. При наличии отдельного диска с записями создайте snapshot и для него либо используйте резервное копирование хранилища.
4. Запишите текущий внешний и внутренний IP-адреса, правила Security Group, подключённые диски и параметры сети.
5. Убедитесь, что в хранилище MikoPBX свободно не менее **400 МБ**.
6. Проверьте наличие доступа к serial console или web console провайдера. Она понадобится, если после перезагрузки сеть не поднимется автоматически.
7. Запланируйте техническое окно: активные вызовы будут завершены.

{% hint style="warning" %}
Не создавайте новую VM из `.img`, предназначенного для встроенного обновления, если облако требует RAW, VHD или собственный формат импорта. Формат установочного образа облака и файл обновления MikoPBX — разные вещи.
{% endhint %}

## Онлайн-обновление

1. Войдите в web-интерфейс MikoPBX.
2. Откройте **Обслуживание** → **Обновление PBX**.
3. Найдите требуемую версию в таблице **Доступны онлайн обновления**.
4. Ознакомьтесь со списком изменений и запустите загрузку.
5. После завершения загрузки введите фразу **Да, у меня есть резервная копия**.
6. Нажмите **Обновить**.
7. Не выполняйте Restart или Stop из панели облака: MikoPBX сама подготовит обновление и перезагрузится.

Во время перезагрузки соединение с web-интерфейсом прервётся. Следить за процессом безопаснее через serial console или web console облачного провайдера.

## Обновление скачанным IMG-файлом

Используйте локальный файл, если версия отсутствует в списке или облачная VM не имеет прямого доступа к серверу обновлений.

1. Скачайте `.img` нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).
2. Проверьте, что архитектура образа совпадает с архитектурой VM.
3. Откройте **Обслуживание** → **Обновление PBX**.
4. Выберите скачанный `.img` и нажмите **Применить обновление**.
5. Введите фразу **Да, у меня есть резервная копия** и подтвердите операцию.
6. Дождитесь автоматической перезагрузки и повторного запуска сервисов.

{% hint style="info" %}
Встроенный механизм обновления рассчитан на штатную дисковую установку MikoPBX с загрузочным разделом, разделом конфигурации `/cf` и подключённым Storage. Он не предназначен для Docker и LXC.
{% endhint %}

## Можно ли обновить облачную VM через ISO

Обновление через ISO возможно только тогда, когда облачная платформа одновременно позволяет:

* загрузить или подключить пользовательский ISO;
* изменить порядок загрузки VM;
* открыть интерактивную консоль;
* после обновления отключить ISO и снова загрузиться с системного диска.

Если все условия выполняются, порядок действий совпадает с обычной виртуальной машиной:

1. Подключите ISO нужной версии.
2. Загрузите VM в Recovery mode.
3. Откройте **Install / Repair**.
4. Выберите **Update to version ...**.
5. После завершения отключите ISO и загрузитесь с системного диска.

{% hint style="danger" %}
Не выбирайте **Install**: этот пункт предназначен для новой установки и может удалить данные на выбранном диске.
{% endhint %}

Если провайдер не поддерживает ISO, не пытайтесь имитировать этот способ заменой системного диска. Используйте web-обновление либо восстановление из snapshot.

## Проверка после обновления

1. Убедитесь в панели облака, что VM работает и прошла health checks.
2. Проверьте внешний и внутренний IP-адреса.
3. Откройте web-интерфейс и проверьте установленную версию.
4. Проверьте регистрацию SIP-провайдеров и телефонов.
5. Выполните тестовые входящий и исходящий звонки.
6. Проверьте Security Group, облачный firewall и правила MikoPBX.
7. Убедитесь, что дополнительный диск Storage подключён и записи доступны.

## Откат

Если новая версия не запускается или потеряна сеть:

1. Откройте консоль VM и убедитесь, что обновление уже завершилось.
2. Если загрузка завершилась с ошибкой, выключите VM средствами облачной платформы.
3. Восстановите snapshot системного диска или создайте новый диск из snapshot и подключите его как загрузочный.
4. При необходимости восстановите отдельный snapshot Storage.
5. Проверьте соответствие IP-адресов, дисков и правил Security Group исходным значениям.

Не удаляйте snapshots до проверки телефонии, записей разговоров и всех интеграций.
