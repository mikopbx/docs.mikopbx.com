# Обновление MikoPBX на физическом сервере

Эта инструкция подходит для отдельного компьютера или сервера, на диск которого установлена MikoPBX.

Основной способ — обновление через web-интерфейс. Если станция не загружается штатно или web-интерфейс недоступен, используйте ISO-образ, записанный на отдельный USB-носитель.

{% hint style="danger" %}
Перед обновлением обязательно создайте резервную копию настроек и сохраните её на другом устройстве. Если записи разговоров критичны, отдельно скопируйте их с диска Storage.
{% endhint %}

## Подготовка

1. Убедитесь, что у вас есть физический доступ к серверу либо рабочая IPMI/KVM-консоль.
2. Создайте резервную копию настроек MikoPBX и скачайте её на компьютер администратора.
3. Проверьте состояние системного диска и диска Storage.
4. Убедитесь, что в Storage свободно не менее **400 МБ**.
5. Если операционная система и Storage находятся на одном физическом диске, убедитесь, что резервная копия записей хранится вне этого диска.
6. Подключите сервер к источнику бесперебойного питания.
7. Завершите активные вызовы и запланируйте перерыв в работе телефонии.

{% hint style="warning" %}
В актуальном механизме обновления раздел Storage на единственном системном диске сохраняется. Тем не менее ошибка диска или отключение питания во время переразметки может привести к потере данных, поэтому внешняя резервная копия всё равно необходима.
{% endhint %}

## Обновление через web-интерфейс

### Онлайн-обновление

1. В web-интерфейсе откройте **Обслуживание** → **Обновление PBX**.
2. Выберите требуемую версию в списке онлайн-обновлений.
3. Ознакомьтесь со списком изменений и запустите загрузку.
4. После загрузки введите фразу **Да, у меня есть резервная копия**.
5. Нажмите **Обновить**.

MikoPBX запишет сценарий обновления в загрузочный раздел и перезагрузит сервер. Обновление системного диска будет выполнено на раннем этапе загрузки.

### Обновление локальным IMG-файлом

1. Скачайте `.img` нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).
2. Откройте **Обслуживание** → **Обновление PBX**.
3. Выберите скачанный файл `.img`.
4. Нажмите **Применить обновление**.
5. Введите фразу **Да, у меня есть резервная копия** и подтвердите операцию.
6. Дождитесь автоматической перезагрузки.

{% hint style="info" %}
Не записывайте файл обновления `.img` непосредственно на работающий системный диск командой `dd`. Встроенный механизм сначала подготавливает загрузочный раздел и выполняет обновление после перезагрузки.
{% endhint %}

## Обновление с ISO на USB-носителе

Этот способ подходит для восстановления и обновления станции с локальной консоли.

### Создание загрузочного носителя

1. Скачайте ISO нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).
2. Подключите отдельную USB-флешку объёмом не менее 1 ГБ.
3. Запишите ISO в режиме образа диска с помощью Rufus, balenaEtcher или `dd`.

{% hint style="danger" %}
При записи ISO все данные на выбранной USB-флешке будут удалены. Внимательно проверьте выбранное устройство.
{% endhint %}

### Запуск обновления

1. Подключите подготовленную флешку к серверу.
2. В BIOS/UEFI или Boot Menu выберите загрузку с USB.
3. Дождитесь запуска MikoPBX в Recovery mode.
4. Откройте **Install / Repair**.
5. Выберите **Update to version ...** — **Обновить до версии ...**.
6. Дождитесь окончания записи и перезагрузки.
7. Извлеките USB-флешку либо верните системный диск на первое место в порядке загрузки.

{% hint style="danger" %}
Пункт **Install** предназначен для новой установки и удаляет данные на выбранном устройстве. Для обновления с сохранением настроек выбирайте только **Update to version ...**.
{% endhint %}

## Проверка после обновления

1. Убедитесь по локальной или IPMI-консоли, что система загрузилась с внутреннего диска.
2. Откройте web-интерфейс и проверьте номер версии.
3. Проверьте доступность Storage и старых записей разговоров.
4. Проверьте сетевые интерфейсы, шлюз и DNS.
5. Убедитесь, что зарегистрировались телефоны и SIP-провайдеры.
6. Выполните входящий и исходящий тестовые звонки.

## Если станция не загружается

1. Проверьте, не осталась ли загрузочная флешка первым устройством в BIOS/UEFI.
2. Снова загрузитесь с ISO и откройте Recovery mode.
3. Не запускайте новую установку, пока не убедитесь, что резервная копия доступна.
4. При признаках аппаратной ошибки проверьте SMART диска и кабели питания/данных.
5. Если системный диск повреждён, установите MikoPBX на исправный диск и восстановите конфигурацию из резервной копии.
