# Обновление MikoPBX на виртуальной машине

Эта инструкция подходит для MikoPBX, установленной как полноценная виртуальная машина в VMware, VirtualBox, Hyper-V, KVM, Proxmox VE и других гипервизорах.

Для такой установки доступны два способа обновления:

* **через web-интерфейс** — основной и наиболее удобный способ;
* **с ISO-образа** — резервный способ, если web-интерфейс недоступен или требуется восстановление системы.

{% hint style="danger" %}
Перед обновлением обязательно создайте резервную копию настроек MikoPBX. Дополнительно рекомендуется создать snapshot виртуальной машины средствами гипервизора.
{% endhint %}

## Подготовка

1. Убедитесь, что у вас есть доступ к web-интерфейсу и консоли виртуальной машины.
2. Создайте резервную копию настроек MikoPBX.
3. Создайте snapshot виртуальной машины. Если гипервизор позволяет, снимайте его при выключенной виртуальной машине.
4. Убедитесь, что в хранилище MikoPBX свободно не менее **400 МБ**.
5. Запланируйте техническое окно: во время обновления MikoPBX перезагрузится, а текущие вызовы будут завершены.

{% hint style="warning" %}
Не выключайте виртуальную машину и не выполняйте принудительный сброс во время записи обновления.
{% endhint %}

## Обновление через web-интерфейс

### Обновление до версии из списка

1. Откройте web-интерфейс MikoPBX.
2. Перейдите в раздел **Обслуживание** → **Обновление PBX**.
3. В таблице **Доступны онлайн обновления** найдите нужную версию.
4. Ознакомьтесь со списком изменений и нажмите кнопку обновления напротив выбранной версии.
5. Дождитесь загрузки образа. Не закрывайте страницу до появления окна подтверждения.
6. Введите фразу **Да, у меня есть резервная копия**.
7. Нажмите **Обновить**.

MikoPBX подготовит обновление и автоматически перезагрузит виртуальную машину. Само обновление выполняется при следующей загрузке до подключения рабочих разделов.

### Обновление локальным IMG-файлом

Этот способ подходит, если нужной версии нет в списке онлайн-обновлений или файл уже скачан заранее.

1. Скачайте файл нужной версии с расширением `.img` со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).
2. В web-интерфейсе откройте **Обслуживание** → **Обновление PBX**.
3. В поле выбора файла укажите скачанный `.img`.
4. Нажмите **Применить обновление**.
5. Введите фразу **Да, у меня есть резервная копия**.
6. Подтвердите обновление и дождитесь перезагрузки.

{% hint style="info" %}
Форма обновления принимает именно файл `.img`. ISO, RAW, VHD и архив LXC для этого способа не подходят.
{% endhint %}

## Обновление с ISO-образа

Используйте этот вариант, если станция не загружается штатно, web-интерфейс недоступен либо требуется выполнить обновление из Recovery mode.

1. Скачайте ISO-образ нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).
2. Выключите виртуальную машину.
3. В настройках гипервизора подключите ISO к виртуальному CD/DVD-приводу.
4. Установите загрузку с виртуального CD/DVD раньше системного диска.
5. Запустите виртуальную машину и откройте её консоль.
6. Дождитесь сообщения о загрузке в режиме восстановления — **System booted in recovery mode (Live CD)**.
7. Откройте пункт **Install / Repair**.
8. Выберите **Update to version ...**. В русской локализации пункт называется **Обновить до версии ...**.

{% hint style="danger" %}
Не выбирайте пункт **Install**. Он запускает новую установку и предупреждает об удалении данных на выбранном диске. Для обновления с сохранением настроек нужен пункт **Update to version ...**.
{% endhint %}

После завершения операции:

1. Выключите виртуальную машину, если ISO не был отключён автоматически.
2. Отключите ISO от виртуального привода.
3. Верните загрузку с системного диска на первое место.
4. Запустите виртуальную машину.

## Проверка после обновления

1. Откройте web-интерфейс и проверьте номер версии в нижней части страницы.
2. Убедитесь, что доступны сотрудники, провайдеры, маршруты и модули.
3. Проверьте регистрацию SIP-провайдеров и телефонов.
4. Выполните входящий и исходящий тестовые звонки.
5. Проверьте наличие записей разговоров и свободное место в разделе **Хранилище**.
6. Не удаляйте snapshot до завершения всех проверок.

## Если обновление не завершилось

* Если станция снова загружается с ISO, отключите образ и проверьте порядок загрузки.
* Если web-интерфейс временно недоступен, дождитесь завершения загрузки и проверьте консоль виртуальной машины.
* Если новая версия не запускается, выключите виртуальную машину и восстановите snapshot.
* Если snapshot отсутствует, загрузитесь с ISO и используйте Recovery mode.

После успешной проверки удалите старый snapshot, чтобы он не занимал место в хранилище гипервизора.
