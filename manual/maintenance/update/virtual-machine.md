# Обновление виртуальной машины

{% hint style="warning" %}
Рекомендуется производить обновления последовательно, «не перепрыгивая» через релизы и версии.
{% endhint %}

Эта инструкция подходит для MikoPBX, установленной как полноценная виртуальная машина в VMware, VirtualBox, Hyper-V, KVM, Proxmox VE и других гипервизорах.

Для такой установки доступны два способа обновления:

* **через web-интерфейс** — основной и наиболее удобный способ;
* **с ISO-образа** — резервный способ, если web-интерфейс недоступен или требуется восстановление системы.

{% hint style="danger" %}
Перед обновлением обязательно создайте резервную копию настроек MikoPBX. Дополнительно рекомендуется создать snapshot виртуальной машины средствами гипервизора.
{% endhint %}

## Подготовка

1. Убедитесь, что у вас есть доступ к web-интерфейсу и консоли виртуальной машины. Создайте резервную копию настроек MikoPBX и записей разговоров.
2. Создайте snapshot виртуальной машины. Если гипервизор позволяет, снимайте его при выключенной виртуальной машине.
3. Убедитесь, что на системном диске свободно не менее **400 МБ**.
4. Запланируйте техническое окно: во время обновления MikoPBX перезагрузится, а текущие вызовы будут завершены.

{% hint style="warning" %}
Не выключайте виртуальную машину и не выполняйте принудительный сброс во время записи обновления.
{% endhint %}

## Обновление через web-интерфейс

### Обновление до версии из списка

1. Откройте web-интерфейс MikoPBX.
2. Перейдите в раздел **Обслуживание** → **Обновление PBX**.

<figure><img src="../../../.gitbook/assets/PBXUpdate_Section.png" alt=""><figcaption><p>Раздел "Обновление PBX"</p></figcaption></figure>

3. В таблице "**Доступны онлайн обновления"** найдите нужную версию. Ознакомьтесь со списком изменений и нажмите кнопку обновления напротив выбранной версии.

<figure><img src="../../../.gitbook/assets/updatePBXFromWeb.png" alt=""><figcaption><p>Кнопка для обновления станции из веб интерфейса</p></figcaption></figure>

4. Дождитесь загрузки образа. Не закрывайте страницу до появления окна подтверждения. Введите фразу "**Да, у меня есть резервная копия"**. Нажмите **Обновить**.

<figure><img src="../../../.gitbook/assets/MikoPBX_UpdateConfirmation.png" alt=""><figcaption><p>Подтверждение наличия резервной копии</p></figcaption></figure>

MikoPBX подготовит обновление и автоматически перезагрузит виртуальную машину.&#x20;

### Обновление локальным IMG-файлом

Этот способ подходит, если нужной версии нет в списке онлайн-обновлений или файл уже скачан заранее.

1. Скачайте файл нужной версии с расширением `.img` со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).

{% hint style="info" %}
Обратите внимание на архитектуру Вашей MikoPBX: в случае если у Вас ARM MikoPBX, то используйте файл обновления с "arm64" в названии. Если у Вас X86 MikoPBX, то используйте файл обновления с "x86\_64" в названии.
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXGithubReleases-IMG.png" alt=""><figcaption><p>Загрузка .img для обновления</p></figcaption></figure>

2. В web-интерфейсе откройте **Обслуживание** → **Обновление PBX**.

<figure><img src="../../../.gitbook/assets/PBXUpdate_Section.png" alt=""><figcaption><p>Раздел "Обновление PBX"</p></figcaption></figure>

3. В поле выбора файла укажите скачанный `.img`.

{% hint style="info" %}
Форма обновления принимает именно файл `.img`. ISO, RAW, VHD и архив LXC для этого способа не подходят.
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXUpdate_ChooseIMG.png" alt=""><figcaption><p>Поле для выбора файла обновления</p></figcaption></figure>

4. Нажмите **Применить обновление**.

<figure><img src="../../../.gitbook/assets/MikoPBX_ApplyUdate.png" alt=""><figcaption><p>Кнопка "Применить обновление"</p></figcaption></figure>

5. Введите фразу "**Да, у меня есть резервная копия"**. Подтвердите обновление и дождитесь перезагрузки.

<figure><img src="../../../.gitbook/assets/MikoPBX_UpdateConfirmation.png" alt=""><figcaption><p>Подтверждение наличия резервной копии</p></figcaption></figure>

## Обновление с ISO-образа

Используйте этот вариант, если станция не загружается штатно, web-интерфейс недоступен либо требуется выполнить обновление из Recovery mode.

1. Скачайте ISO-образ нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).

{% hint style="info" %}
Обратите внимание на архитектуру Вашей MikoPBX: в случае если у Вас ARM MikoPBX, то используйте файл обновления с "arm64" в названии. Если у Вас X86 MikoPBX, то используйте файл обновления с "x86\_64" в названии.
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXGithubReleases-ISO.png" alt=""><figcaption><p>Загрузка .iso c GitHub MikoPBX</p></figcaption></figure>

2. Выключите виртуальную машину. В настройках гипервизора подключите ISO к виртуальному CD/DVD-приводу и установите загрузку с виртуального CD/DVD раньше системного диска.

<figure><img src="../../../.gitbook/assets/attachISOToVMUTM.png" alt=""><figcaption><p>Пример подключенного .iso в гипервизоре UTM</p></figcaption></figure>

3. Запустите виртуальную машину и откройте её консоль.
4. Дождитесь сообщения о загрузке в режиме восстановления — **System booted in recovery mode (Live CD)**.

<figure><img src="../../../.gitbook/assets/MikoPBX-RecoveryMode3.40.png" alt=""><figcaption><p>Загруженная MikoPBX в Recovery mode</p></figcaption></figure>

5. Нажмите на любую клавишу, чтобы перейти к консольному меню. Далее откройте **"\[4] Install or recover"**.

<figure><img src="../../../.gitbook/assets/MikoPBX-3.40-InstallOrRecover.png" alt=""><figcaption><p>Раздел "Install or recover" в консольном меню MikoPBX</p></figcaption></figure>

6. Выберите "**Update to version...".** В русской локализации пункт называется "**Обновить до версии...".**

{% hint style="danger" %}
Не выбирайте пункт **Install**. Он запускает новую установку и предупреждает об удалении данных на выбранном диске. Для обновления с сохранением настроек нужен пункт **Update to version ...**.
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXConsole-UpdateTo3.40.png" alt=""><figcaption><p>Обновление версии на 2026.3.40</p></figcaption></figure>

После завершения операции:

1. Выключите виртуальную машину, если ISO не был отключён автоматически.
2. Отключите ISO от виртуального привода.
3. Верните загрузку с системного диска на первое место.
4. Запустите виртуальную машину.

<figure><img src="../../../.gitbook/assets/UpdatedMikoPBX2026.3.40.png" alt=""><figcaption><p>Обновленная MikoPBX на версию 2026.3.40</p></figcaption></figure>
