# Обновление в облаке

{% hint style="warning" %}
Рекомендуется производить обновления последовательно, «не перепрыгивая» через релизы и версии.
{% endhint %}

Эта инструкция предназначена для MikoPBX, работающей как полноценная облачная виртуальная машина: из Marketplace либо из импортированного RAW, VHD или другого дискового образа.

{% hint style="info" %}
Встроенный механизм обновления рассчитан на штатную дисковую установку MikoPBX с загрузочным разделом, разделом конфигурации `/cf` и подключённым Storage. Он не предназначен для Docker и LXC.
{% endhint %}

Основной способ обновления облачной станции — через web-интерфейс с использованием `.img`-образа. Возможность загрузки с ISO зависит от конкретного облачного провайдера и не является универсальной.

{% hint style="danger" %}
Перед обновлением создайте две независимые точки восстановления: резервную копию настроек MikoPBX и snapshot системного диска или всей виртуальной машины в панели облачного провайдера.
{% endhint %}

## Перед началом

1. Проверьте, что у вас есть доступ к панели управления облаком и web-интерфейсу MikoPBX. Сохраните резервную копию настроек MikoPBX, а так же записей разговоров вне обновляемой виртуальной машины.
2. Создайте snapshot системного диска. При наличии отдельного диска с записями создайте snapshot и для него либо используйте резервное копирование хранилища.
3. Запишите текущий внешний и внутренний IP-адреса, правила Security Group, подключённые диски и параметры сети.
4. Убедитесь, что на системном диске с MikoPBX свободно не менее **400 МБ**.
5. Запланируйте техническое окно: активные вызовы будут завершены.

## Онлайн-обновление

1. Войдите в web-интерфейс MikoPBX.
2. Откройте "**Обслуживание"** → "**Обновление PBX"**.

<figure><img src="../../../.gitbook/assets/PBXUpdate_Section.png" alt=""><figcaption><p>Раздел "Обновление PBX"</p></figcaption></figure>

3. Найдите необходимую версию в таблице "**Доступны онлайн обновления"**. Ознакомьтесь со списком изменений и запустите загрузку.

<figure><img src="../../../.gitbook/assets/updatePBXFromWeb.png" alt=""><figcaption></figcaption></figure>

4. После завершения загрузки введите фразу "**Да, у меня есть резервная копия"**. Нажмите **Обновить**.

<figure><img src="../../../.gitbook/assets/MikoPBX_UpdateConfirmation.png" alt=""><figcaption><p>Подтверждение наличия резервной копии</p></figcaption></figure>

5. Не выполняйте Restart или Stop из панели облака: MikoPBX сама подготовит обновление и перезагрузится. Во время перезагрузки соединение с web-интерфейсом прервётся. Следить за процессом безопаснее через serial console или web console облачного провайдера.

## Обновление скачанным IMG-файлом

Используйте локальный файл, если версия отсутствует в списке или облачная VM не имеет прямого доступа к серверу обновлений.

1. Скачайте `.img` нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).

{% hint style="info" %}
Обратите внимание на архитектуру Вашей MikoPBX: в случае если у Вас ARM MikoPBX, то используйте файл обновления с "arm64" в названии. Если у Вас X86 MikoPBX, то используйте файл обновления с "x86\_64" в названии.
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXGithubReleases-IMG.png" alt=""><figcaption></figcaption></figure>

2. Проверьте, что архитектура образа совпадает с архитектурой VM.
3. Откройте **Обслуживание** → **Обновление PBX**.

<figure><img src="../../../.gitbook/assets/PBXUpdate_Section.png" alt=""><figcaption><p>Раздел "Обслуживание" -> "Обновление PBX"</p></figcaption></figure>

4. Выберите скачанный `.img` и нажмите **Применить обновление**.

<figure><img src="../../../.gitbook/assets/MikoPBX_ApplyUdate.png" alt=""><figcaption><p>Применение обновления</p></figcaption></figure>

5. Введите фразу "**Да, у меня есть резервная копия"** и подтвердите операцию.

<figure><img src="../../../.gitbook/assets/MikoPBX_UpdateConfirmation.png" alt=""><figcaption><p>Подтверждение наличия резервной копии</p></figcaption></figure>

6. Дождитесь автоматической перезагрузки и повторного запуска сервисов.

## Можно ли обновить облачную VM через ISO

Обновление через ISO возможно только тогда, когда облачная платформа одновременно позволяет:

* загрузить или подключить пользовательский ISO;
* изменить порядок загрузки VM;
* открыть интерактивную консоль;
* после обновления отключить ISO и снова загрузиться с системного диска.

{% hint style="danger" %}
Если провайдер не поддерживает ISO, не пытайтесь имитировать этот способ заменой системного диска. Используйте web-обновление либо восстановление из snapshot.
{% endhint %}

Если все условия выполняются (например как [в Vultr](../../../setup/cloud/vultr.md)), порядок действий совпадает с обычной виртуальной машиной:

1. Скачайте и подключите ISO-образ нужной версии со страницы [релизов MikoPBX](https://github.com/mikopbx/Core/releases).

<figure><img src="../../../.gitbook/assets/MikoPBXGithubReleases-ISO.png" alt=""><figcaption><p>Загрузка .iso c GitHub MikoPBX</p></figcaption></figure>

2. Запустите машину и откройте её консоль. Дождитесь сообщения о загрузке в режиме восстановления — **System booted in recovery mode (Live CD)**.

<figure><img src="../../../.gitbook/assets/MikoPBX-RecoveryMode3.40.png" alt=""><figcaption><p>Загруженная MikoPBX в Recovery mode</p></figcaption></figure>

3. Нажмите на любую клавишу, чтобы перейти к консольному меню. Далее откройте **"\[4] Install or recover"**.

<figure><img src="../../../.gitbook/assets/MikoPBX-3.40-InstallOrRecover.png" alt=""><figcaption><p>Раздел "Install or recover" в консольном меню MikoPBX</p></figcaption></figure>

4. Выберите "**Update to version...".** В русской локализации пункт называется "**Обновить до версии...".**

{% hint style="danger" %}
Не выбирайте пункт **Install**. Он запускает новую установку и предупреждает об удалении данных на выбранном диске. Для обновления с сохранением настроек нужен пункт **Update to version...**
{% endhint %}

<figure><img src="../../../.gitbook/assets/MikoPBXConsole-UpdateTo3.40.png" alt=""><figcaption><p>Обновление версии на 2026.3.40</p></figcaption></figure>

5. После завершения отключите ISO и загрузитесь с системного диска.
