# МТС

Чтобы подключить провайдера МТС к MikoPBX, нужно подключить услугу “**Автосекретарь**”. Для ознакомления с её описанием необходимо перейти по [ссылке](https://business.mts.ru/kbr/uslugi/avtosekretar_personalnyi), либо оставить заявку, чтобы Вам перезвонили, либо самостоятельно позвонить на номер 8 (800) 250-09-90.

\
Вам предоставляется многоканальный номер для входящих звонков и доступ в личный кабинет автосекретаря МТС - **aa.mts.ru**, где можно привязать любые номера для принятия этих звонков по правилам, которые зададите Вы. Чтобы получить учётную запись для подключения к MikoPBX необходимо сообщить об этом сотрудникам МТС и зарегистрировать соответствующую заявку. В результате Вам на электронную почту должен прийти опросный лист, где Вы указываете свои анкетные данные и **обязательно** пишите, чтобы доступ предоставили посредством **логина и пароля**. По умолчанию привязка осуществляется по ip-адресу. Отсылаете этот лист обратно в компанию и получаете второй опросный лист, где уже заполняете данные для подключения провайдера посредством логина и пароля. На регистрацию Ваших данных уходит несколько дней, в результате Вам на почту приходят учётные данные следующего вида:

```markup
логин: 910740****U2383 
пароль: ****************

Адрес регистратора SIP registrar server:
212.188.36.179 или reg.aa.mts.ru udp/5060
Дополнительная информация (для открытия доступа в acl):
адрес RTP сессий 212.188.36.187 (udp)
диапазон RTP портов udp/16384-udp/39999
```
