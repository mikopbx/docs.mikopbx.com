# Телфин

Личный кабинет доступен по [ссылке](https://cabinet.telphin.ru/). При подключении номера провайдер присылает на контактный email письмо с параметрами подключения:

> Уважаемый клиент,
>
> Линия номер: 00019XXXX
>
> Пароль устройства: XXXXXXX
>
> Номер 7495276XXXX
>
>
>
> ВНИМАНИЕ: при повторном запросе пароля устройства он будет изменен!
>
>
>
> Городской/мобильный номер, подключенный к линии вы можете увидеть в Личном кабинете в разделе:
>
> [Услуги](https://cabinet.telphin.ru/lines)
>
> К письму приложен файл (вложение\attachment) со всеми необходимыми данными для настройки вашего оборудования.
>
> Просьба внимательно изучить их и приложенные ссылки на инструкции до начала настройки вашего оборудования!
>
> ЭТО АВТОМАТИЧЕСКОЕ СООБЩЕНИЕ. ПРОСЬБА НЕ ОТВЕЧАТЬ НА НЕГО.

Инструкции по подключению для asterisk можно найти по [ссылке](https://www.telphin.ru/subscribers/configuring-ip-atc?utm_source=klient\&utm_medium=referral\&utm_campaign=uchetnye_dannye/). Инструкции довольно путанные, попробуем их предельно упростить.

### Добавление провайдера

1. "**Маршрутизация**" - "**Провайдеры телефонии**" - добавьте нового провайдера
2. "**Название провайдера**" - произвольное имя провайдера, к примеру "Телфин"
3. "**Тип учетной записи**" - "**Исходящая регистрация"**
4. "**Хост или IP адрес**" - voice.telphin.com
5. "**Логин**" - см. письмо от провайдера "`Линия номер: 00019XXXX`"
6. "**Пароль**" - см. письмо от провайдера  "`Пароль устройства: XXXXXXX`"
7. "**Расширенные настройки**" - "**Порт соединения SIP**" - укажите `5068`
8. "**Расширенные настройки**" -  "**Дополнительные адреса провайдера**"  - перечислите адреса **`213.170.92.166`**, **46.229.221.86**, **`188.43.252.147`**, после ввода адреса обязательно нажмите **ENTER** для добавления адреса в список
9. Сохраните настройки

### Входящий маршрут

1. "**Маршрутизация**" - "**Входящие маршруты**" - добавьте новый маршрут
2. "**Провайдер**" - выберите "**Телфин**"
3. "**Дополнительный номер (DID)**" - см. письмо от провайдера "`Линия номер: 00019XXXX`"
4. "**Вызов будет переадресован на**" - укажите номер назначения
5. Сохраните настройки

### Исходящий маршрут

1. "**Маршрутизация**" - "**Исходящие маршруты**" - добавьте новый маршрут
2. "**Название правила**" - произвольное наименование, к примеру "Исходящие Телфин"
3. "**Номер начинается с**" - для звонков по РФ можно указать значение `(7|8)`&#x20;
4. "**Остальная часть номера состоит из указанного количества цифр**" - укажите значение `10`&#x20;
5. "**Перед тем как начать звонок отсекаем**" - отсекаем **`1` символ**
6. **"Цифр в начале номера, затем добавляем в начало" -** добавляем цифру `7`&#x20;
7. "**Направить вызов через провайдера**" - выберите провайдера Телфин
8. Сохраните настройки
