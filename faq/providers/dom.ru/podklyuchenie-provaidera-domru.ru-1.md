# Подключение провайдера domru.ru

Провайдер обычно присылает следующие параметры для подключения:

* — короткий номер, пример **6401111**
* — 11ти значный номер, пример **74852231111**
* **voip.domru.ru** — адрес для подключения (188.234.136.49)
* **пароль** для подключения

## Пример настройки провайдера

{% stepper %}
{% step %}
### Перейдите в web-интерфейс MikoPBX
{% endstep %}

{% step %}
### Создайте нового провайдера [см. раздел Провайдеры телефонии](https://wiki.mikopbx.ru/providers)
{% endstep %}

{% step %}
### Укажите наименование, например «**MIKO Dom.ru**»
{% endstep %}

{% step %}
### Заполните поле «**Хост**» - [**voip.domru.ru**](http://voip.domru.ru/)
{% endstep %}

{% step %}
### В качестве логина укажите короткий номер, к примеру **6401111**
{% endstep %}

{% step %}
### Заполните пароль
{% endstep %}

{% step %}
### Перейдите в «Расширенные настройки»
{% endstep %}

{% step %}
### Заполните **User** - 11ти значный номер телефона, к примеру **74852231111**
{% endstep %}

{% step %}
### Заполните поле «Дополнительные атрибуты PJSIP»:
{% endstep %}
{% endstepper %}

Пример дополнительных атрибутов:

```ini
[registration]
client_uri=sip:78126401111@voip.domru.ru:5060

[registration-auth]
username = 6401111

[auth] 
username = 6401111
```
