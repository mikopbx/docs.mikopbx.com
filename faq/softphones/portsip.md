# PortSIP

{% hint style="info" %}
Ссылка на загрузку софтфона - [здесь](https://www.portsip.com/download-portsip-softphone/).
{% endhint %}

Ниже на скриншоте представлены необходимые данные для SIP-покдлючения:

<figure><img src="../../.gitbook/assets/sipConnectionParameters.jpg" alt=""><figcaption><p>Параметры для SIP-подключения</p></figcaption></figure>

1. В стартовом окне введите **IP-адрес** станции MikoPBX.

Нажмите "**Done**"

<figure><img src="../../.gitbook/assets/SIPDomain.jpg" alt=""><figcaption><p>Поле "SIP Domain"</p></figcaption></figure>

2. Далее укажите:

* Внутренний номер сотрудника
* Пароль для SIP
* Выберите язык

Нажмите "**Войти**":

<figure><img src="../../.gitbook/assets/parametersPortSIP.jpg" alt=""><figcaption><p>Параметры для SIP-подключения</p></figcaption></figure>

Произойдет авторизация. Понять, что она была успешной Вы можете по индикатору в интерфейсах PortSIP и MikoPBX.

<figure><img src="../../.gitbook/assets/successfulConnectionPortSIP.jpg" alt=""><figcaption><p>Индикатор подключения в интерфейсе PortSIP</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/successfulConnectionMikoPBX.jpg" alt=""><figcaption><p>Индикатор подключения в интерфейсе MikoPBX</p></figcaption></figure>
