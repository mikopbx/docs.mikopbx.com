# Перестает работать сеть в MikoPBX

Если в настройках MikoPBX установлена галочка **Обновлять внешний ip адрес при каждой перезагрузке**, система автоматически запрашивает текущий внешний IP-адрес.&#x20;

Недавно сервис изменил формат ответа, и теперь вместо IP-адреса он возвращает HTML-страницу. Это приводит к некорректному обновлению внешнего IP-адреса в системе, нарушает сетевое соединение и может создавать проблемы при регистрации в маркетплейсе и получении нового ключа/регистрации существующего ключа.

Для устранения проблемы выполните следующие шаги:

1. Перейдите в настройки сети MikoPBX: **Сеть и Firewall** / **Сетевые интерфейсы**.
2. Отключите галочку **Обновлять внешний ip адрес при каждой перезагрузке**.
3. Очистите поле **Внешний IP-адрес вашего маршрутизатора** от некорректных данных и пропишите руками верный IP-адрес.
4. Сохраните изменения и перезагрузите АТС.
