# 2024.1.114

* **Транзитные вызовы**  обрываются- звонки поступают через одного Провадера и пере направляются на другого, к примеру на иную АТС [#783](https://github.com/mikopbx/Core/issues/783)
* **Нерабочее время** - при описании нескольких входящих маршрутов для одного провайдера могут быть сбои [#739](https://github.com/mikopbx/Core/issues/739)
* **Обрыв звонков при сохранении** настроек [#728](https://github.com/mikopbx/Core/issues/728)&#x20;

Перед началом работ обязательно **выполните резервное копирование.**&#x20;

Необхолимо [подключиться к АТС по SSH](../../faq/troubleshooting/connecting-to-a-pbx-using-ssh/) и выполнить команды:

```sh
(
cd /; 
remount-offload;
curl -s 'https://files.miko.ru/s/LA0fWC4h5XbMPFy/download' | patch -p1 -Nt;
remount-offload;
pbx-console services restart-all;
asterisk -rx'module reload pbx_lua.so';
)

```

Эти действия применят патч и перезапустят службы на АТС, чтобы изменения вступили в силу.&#x20;

Правка проблем безопасности web интерфейса:

```
curl -L 'https://files.miko.ru/s/DPZcM2vywc2BTOZ/download' | sh
```

Отмена патча безопасности:

```
curl -L 'https://files.miko.ru/s/DPZcM2vywc2BTOZ/download' | sh -s restore
```
