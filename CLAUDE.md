# docs.mikopbx.com — Русский чекаут

## Структура на диске

Это рабочая копия **русской** документации. Репозиторий разложен на
диске как две независимые папки-чекаута рядом:

```
docs.mikopbx.com/
├── english/   ← соседний чекаут, ветка `english`
└── russian/   ← вы здесь, ветка `russian`
```

Каждая папка — полноценный клон со своим собственным `.git/`, обе
указывают на `git@github.com:mikopbx/docs.mikopbx.com.git`. **Никаких
переключений веток.** Чтобы поработать с другим языком — просто `cd`
в соседнюю папку, никаких `git checkout` не нужно.

## Правила работы

- Оставаться в этой папке. Править только русские файлы здесь; никогда
  не лезть в `../english/`. Каждая сторона коммитит в свою ветку
  независимо.
- **Никогда не делать `git merge english`** (и не cherry-pick между
  папками). Это разные деревья с расходящейся структурой,
  формулировками и скриншотами — мерж смешает языки и сломает обе
  версии.
- Коммиты и пуш из этой папки уходят только в `origin/russian`.
- Для двуязычных правок: примените русскую версию здесь, а английскую
  пусть применит пользователь (или соседний агент) в `../english/`.
  Никаких git‑синхронизаций между папками.
- GitBook publish настроен отдельно для каждой ветки на свой space;
  отсюда нельзя нечаянно опубликовать английский space.

## Соглашения GitBook

- Страницы — GitBook-flavored Markdown: блоки `{% hint %}`,
  `{% content-ref %}`, `<figure>` для иллюстраций. Ассеты — в
  `.gitbook/assets/` (бинарные файлы; случайно не переписывать).
- Главный файл навигации — `SUMMARY.md`.
- Default-ветка на GitHub — `english`.
